# 大肥鱼 v1.0

在 v0.5 的时钟、天气、挥手和句子池上加了八个表情。默认仍是一张不动的经典立绘。

## 这一版有什么

- 八个表情：平常、开心、困、打盹、傲娇、惊讶、担心、兴奋。打盹才戴眼罩。设置页「形象」或串口 `EXPR 0` / `EXPR 1` 切换，存在 NVS。
- 每个表情 24 帧，铺满原来大约 6 秒的动作，一帧大约 250ms。眨眼如果正好落在采样缝里，会换成旁边真正闭上的那一帧。
- 帧是 baseline JPEG，4:2:0，`ffmpeg -q:v 5`。头顶空白不存：平时高 112，平常里有的帧是 128，打盹和兴奋里 Z 或起跳会到 144，贴在 160 高的屏幕底部。八个表情一共 192 帧，大约 825KB。
- 空闲时按时间、气温、天气随机换脸，保持 60 秒。挥手的句子、提醒和余额会盖过这张脸。
- 上次查到的天气和余额写在 NVS。重启先用这份。天气请求失败时不把已经有的结果擦成「天气失败」。
- 字库只留简体 GB2312 一级。以前额外加的繁体人名用字去掉了，那些字显示成「?」。
- 句子池版本 3。生成的句子多一个心情。v0.5 的句子池开机迁移，不丢已有的句子。

旧的表情包（整屏 RGB565，或 zlib 压缩）不能用了。应用和这份 `assets-v1.0.bin` 要一起刷。

## 刷机

用 ESP-IDF 5.4.2 编译。开机串口是 `PET READY v1.0`，表情包正常时还有 `assets ok v20261115 clips 8/8 frames 192`。

应用 `companion-v1.0.bin` 写到 `0x10000`（1,441,600 字节，1.5MB 槽位还剩大约 128KB）。表情包写到 `0x190000`（824,889 字节，2MB 分区还剩大约 1.2MB）。NVS 仍在 `0x9000`。不要整片擦除。

```sh
python -m esptool --chip esp32c3 -b 460800 --before default_reset --after hard_reset write-flash \
  --flash-mode dio --flash-size 4MB --flash-freq 40m \
  0x8000 partition-table.bin \
  0x10000 companion-v1.0.bin \
  0x190000 assets-v1.0.bin
```

引导程序没变过的话，不必写 `0x0` 的 `bootloader.bin`。三个必刷的是分区表、应用、表情包。校验见 `SHA256SUMS`。
