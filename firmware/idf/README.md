# 联网桌宠 v1.0.1（ESP-IDF）

v1.0.1 在下面的 v0.5 行为上加了表情，并修了 v1.0 把整帧解进 RAM、导致联网和网页容易失败的问题。默认仍是经典立绘。

- 设置页「形象」选经典或表情，串口 `EXPR 0` / `EXPR 1` 一样，存在 NVS，默认经典。`EXPR SHOW <名字>` 强制一张脸 30 秒，`EXPR CYCLE` 轮播，`ASSETS` / `ASSETS SELFTEST` 看表情包。
- 八个表情循环：平常、开心、困、打盹、傲娇、惊讶、担心、兴奋。打盹才有眼罩。每张脸 4 帧，大约每 0.9 秒换一帧（眨眼、呼吸），人物位置和 v0.1 一样。试过每张脸只留 2 帧，跳跃更明显，所以仍是 4 帧、只放慢。
- 表情和经典立绘都放在 `assets` 分区（`0x190000`，2 MB），格式 3：按 16 行一条做 LZ4 无损压缩，固件用 `esp_partition_mmap` 从 flash 读压缩字节，只保留约 4 KB 条带缓冲。经典立绘和 v0.5 / v1.0 像素完全一致；表情包缺失或损坏时，用应用里同样压缩的经典图兜底。
- 没开表情、或表情包缺失时，画面和 v0.5 的内置立绘相同。
- 空闲时按时间、气温、天气在候选表情里随机一张，保持 60 秒。深夜且 10 分钟没人摸过会打盹；下午或深夜偏困；下雨或 10°C 以下偏担心；30°C 以上偏困；饭点偏开心。挥手的句子、提醒、余额会盖过空闲表情。余额 ≥ 20 开心，5–20 平常，低于 5 担心，查询失败是傲娇。
- 句子池版本升到 3。生成句多一个心情标签（坏心情改判，不丢句子）。v0.5 的句子池开机迁移，不丢已有的句子。
- 字库只留简体 GB2312 一级。`assets/extra_chars.txt` 里的繁体人名用字拿掉了，那些字会显示成「?」。

开机串口是 `PET READY v1.0.1`。分区布局和 v1.0 相同（NVS 还在 `0x9000`，表情包在 `0x190000`），不要整片擦除。刷应用和表情包（如果还是 v0.5 的分区表，也要刷分区表）：

```
python -m esptool --chip esp32c3 -b 460800 --before default_reset --after hard_reset write_flash --flash_mode dio --flash_size 4MB --flash_freq 40m 0x8000 partition-table.bin 0x10000 companion-v1.0.1.bin 0x190000 assets-v1.0.1.bin
```

镜像、校验和说明在 `releases/v1.0.1/`。GitHub 上的 `.bin` 和预览图以 `.b64` 存放，先运行 `python3 tools/decode_b64_assets.py` 再刷。重做表情包：`python3 tools/gen_expressions.py`（从 `assets/expressions/*.png` 和 `idle.rgb565` 打包，不需要原视频）。

下面是 v0.5 起就有的行为。

## 陪伴模式和生日模式

屏幕是 v0.1 立绘加上方的文字或气泡。有两种模式：

- **陪伴模式**（默认）：上方一张浅色圆角卡片，左边是粗体大号时钟（HH:MM，冒号每秒闪一下），右边是小天气图标（晴 / 多云 / 阴 / 雾 / 雨 / 雪 / 雷，程序画的）和当前气温，细分隔线下面是日期星期（如「11/9 周一」）和天气（如「多云」）。只显示当前气温和天气，不显示最高最低、明天预报和余额。配色跟人物一致（深蓝 / 浅蓝 / 白），人物脸部不被遮挡。卡片下方的深蓝小胶囊只在需要时出现：到点的喝水 / 久坐提醒、联网后 30 秒的 IP、自己设置的屏幕留言。屏幕上不显示生日倒计时，只在生日当天进入生日派对。
- **生日模式**：上方常驻椭圆气泡「祝某某 / 生日快乐」加一个小蛋糕图标；扫一下换成一句生日祝福，7 秒后回来。可以手动切换，也可以设置成生日当天自动切过去，第二天自动回到陪伴模式。

## 生日派对（生日模式）

- 生日模式（手动 `MODE BDAY`，或开了 `BAUTO 1` 时到了设置的月日自动进入，第二天自动回到陪伴模式）：上方气泡「祝某某 / 生日快乐」，右下角有一个程序画的小蛋糕（奶油、草莓、三根条纹蜡烛，火苗每 150 ms 闪一下）。
- 进入生日模式时放一次烟花，之后空闲时每 4 分钟放一次：几枚火箭从下面升起再炸开成彩色粒子，只画在立绘的白色背景上，所以像在人物身后。
- 生日模式下挥手：蜡烛火苗先被吹得歪向一边、闪几下，然后熄灭冒出小灰烟（约 1.2 秒），接着放烟花并弹出一句生日祝福（约 2 秒动画，气泡停留 9 秒）。蜡烛 60 秒后重新点亮。生日模式下不调用任何 API。
- 生日祝福 10 句，写在 `quotes.h` 的 `BIRTHDAY_WISHES`，`{n}` 换成设置的名字，洗牌袋轮换，10 句都说过才重复，也不会连着两次一样；🎂 画成 v0.1 的小蛋糕图标。编译时用三个全宽汉字的名字检查每句都能两行放下；名字太长放不下时退回「名字 / 生日快乐🎂」。
- 字库是简体 GB2312 一级常用字。v1.0 不再额外装繁体人名用字，缺字显示「?」。
- 串口 `BDAYDEMO`：3 分钟内临时显示生日派对（不改日期和模式），马上放烟花，期间 `PET` 演示吹蜡烛；`BDAYDEMO OFF` 提前结束。
- 动画都在显示任务里逐帧画（每帧 40 ms），测距和网页在各自的任务里，不受影响。

## 挥手和动画

- **挥一次手**：播放 v0.1 的「下压回弹」动画（同一张 10 帧缩放表，两次快速下压，约 0.33 秒，气泡不动），同时在人物上方弹出 v0.1 样式的椭圆气泡（白底、深蓝描边、深蓝字，只画椭圆，不带小圆点；立绘原图里自带的两个思考小圆点也在生成字库时擦掉了），显示「大肥鱼」说的一句话，7 秒后回到时间和天气。句子来自句子池，见下文。
- **有提醒时挥手**：关掉提醒，气泡说「喝了就好」或「去走走吧」。
- **挥第二次（距第一次 1 到 10 秒之间）**：查 DeepSeek 余额，气泡先显示「查余额中」，查到后在同一个椭圆气泡里显示一行「余额 ¥22.54」7 秒：金额用和时钟一样的粗体大号数字（25 px 高），「余额」和「¥」用 12px 小字，跟数字底部对齐；金额长了（比如 9999.99）自动按比例缩小，保证放进椭圆，人物照常显示。预览见 `balance-preview.png`（含改之前的两行小字样式）。余额接口 15 秒内不重复请求，太快会显示上次的余额或「稍后再试」。距上一次挥手不到 1 秒的检测算同一次挥手（手还没离开或回波抖动），直接忽略，不播动画也不算第二次；超过 10 秒再挥就是新的一次。第一次挥手照常立刻播动画、弹语录，1 到 10 秒内的第二次再换成余额。串口会打印 `SWEEP single`、`SWEEP double: N ms after first -> balance`、`SWEEP ignored: N ms after previous`。
- 串口 `PET` 等于挥一次手，方便测试。

### 挥手检测

HC-SR04 每 60 ms 测一次。回波宽度由 GPIO 中断记录时间戳，不再用忙等计时，Wi-Fi 任务抢占不会把距离测长。超时和 2 cm 以内、4 m 以外的读数都丢掉。

- 基准距离是最近 9 次正常读数的中位数；连续 5 次没有回波时，基准当作「前方没东西」。
- 读数和基准相差 **超过 20 cm**（可调），而且 **连续 2 次** 都这样，才算一次挥手，并在串口打印 `sweep N: 读数 vs baseline 基准`。
- 算一次之后，要连续 3 次读数回到基准附近（差值小于阈值一半）、并且至少过了 600 ms，才能算下一次。所以挥一下只算一次。
- 东西放在前面超过 5 秒不走，就把它当成新的基准，不会一直触发。
- 阈值用串口 `SWEEP 20` 或网页「挥手灵敏度」修改（5 到 200 cm，存 NVS）。`SONAR 1` 在串口连续打印每次读数和基准，`SONAR 0` 关闭。

气泡和动画移植自 v0.1 的 `firmware/pet.c`：椭圆判定、文字居中、标点后换行、蛋糕图标和下压回弹表都照搬，气泡文字用单独生成的 12px Noto 字库（屏幕其他地方仍是 16px），这样一句话最多两行就能放下。

## 大肥鱼和句子池

「大肥鱼」是中文网友给 DeepSeek 起的外号（鲸鱼标志看着像一条大肥鱼），拟人形象是蓝发少女，和桌宠立绘正好一致：DeepSeek 的萌系小粉丝，蓝头发，爱吃白饭，总是困困的（额头推着眼罩），温柔俏皮、有点傲娇，偶尔自称「本鱼」，爱开鱼的玩笑。完整人设和格式要求都写在 `main/prompts.h` 的系统提示词里，编进固件，原文见下文「DeepSeek 提示词」。

**两行硬限制**：气泡最宽 128 px，两行文字处椭圆内可用宽度约 104 px，12px 字库一个汉字约 12–13 px，一行约 8 个汉字。换行规则：一行放得下就一行；否则只切一刀，优先切在标点后面，其次切在空格处，否则让两行尽量等宽，颜文字括号里不切。

- 编译前：`tools/gen_idf_assets.py` 用和 `display.c` 一样的换行规则检查 `quotes.h` 里的每一句（带 `{temp}` / `{weather}` 的句子先用最宽的值「-10°C」「雷阵雨」填好再量），超过两行或用了字库里没有的字就直接报错退出。
- 设备上：DeepSeek 生成的每一句先去掉组合附加符号（如 •̀ 上的那一点），把占位符换成最宽的值，再用 `display_bubble_fits()` 按实际字宽排版；超过两行、有字库外的字、有未知占位符、有违禁词（政治、币、投资、生日等）、和已有句子重复、标签和内容对不上（比如标了 morning 却写「晚安」）的都丢掉，串口打印 `POOL reject`。显示时用真实的气温和天气填好后再量一次，放不下就换一句。
- 颜文字用到的 ´ ・ ω ｀ ｡ • ᴗ ✧ ＞ ＜ 等字符都加进了字库；Noto 没有的 ᴗ ✧ ◕ ‿ 用 DejaVu Sans 补。

### 句子要贴合此时此刻

每句话都带一个「桶」标签：**时段 × 天气类别**。

| 时段 | 时间 | 天气类别 | 什么时候算 |
|---|---|---|---|
| `morning` | 5–10 点 | `rain` | 天气代码是雨 / 阵雨 / 雷雨（雪不算） |
| `noon` | 11–13 点 | `hot` | 当前气温 ≥ 30°C |
| `afternoon` | 14–16 点 | `cold` | 当前气温 ≤ 10°C |
| `evening` | 17–19 点 | `clear` | 晴（Open-Meteo 代码 0–1） |
| `night` | 20–22 点 | `weekend` | 周六、周日 |
| `late-night` | 23–4 点 | `general` | 任何时候 |
| `any` | 任何时段 | | |

挥手的那一刻，设备算出当前时段和此刻成立的所有天气类别（可以同时成立几个，比如「深夜 + 寒冷 + 晴」），只从「时段是 any 或当前时段」且「天气类别是 general 或此刻成立」的句子里挑。正好为此刻写的句子权重更高：通用句 1，时段对上 +2，天气对上 +2。所以 11 月南昌深夜 7°C 时，大多会说「深夜{temp}，主人快睡吧。」这一类，而不会说「中午啦，吃饭了没」。还没校时只用 `any` 的句子，还没拿到天气就不用带天气类别和占位符的句子。

句子里可以写 `{temp}`（显示时换成「7°C」）和 `{weather}`（换成「晴」「小雨」等），这样一句话能一直跟着实时天气走。串口 `STATUS` 会打印 `context now late-night cold clear` 这样的当前桶，`QUOTE` 一行打印这句的标签。

**句子池**：

- 内置 20 句种子，也都分好了桶（早上 2 句、早上寒冷、中午 2 句、下午、傍晚、晚上晴天、深夜 2 句、下雨、炎热、寒冷、周末，加 6 句通用），加上最多 40 句 DeepSeek 生成的句子。
- 生成的句子和标签、每句被说过的次数、本轮有没有说过、补充次数，整体存成一个带 CRC32 的 NVS blob（约 3 KB），重启、断电都不丢。计数改动后 10 秒写入闪存（每次 3 KB，一天几十次远在 NVS 寿命之内），所以突然拔电最多丢最后几秒的计数。
- 挑句子用「洗牌袋」：在此刻可选的句子里，本轮都说过一遍之前不重复，并且避开最近 6 句。
- 一句话被说满 5 次就退休：生成的句子直接删掉腾位置，内置句子停用；可用的句子少于 8 句时内置句子全部恢复。
- 本轮还没说过的句子少于 20% 时，排队一次**批量补充**：调一次 `deepseek-flash`，系统提示词是完整的人设，用户提示词带上此刻的情况（本地日期时间、星期、工作日 / 周末、季节、地点、当前气温和天气、当前时段和天气类别、模式、最近说过和已有的句子），要 20 句，JSON `{"l":[["时段","天气类别","句子"],...]}`。约 8 句贴合此刻，其余分散到接下来一两天会遇到的时段和天气，约三分之一通用。过滤后存进池子；池子满了就替换已经说过、次数最多的生成句。

### 坏数据保护

开机读句子池时依次检查：blob 大小、版本号、CRC32，然后逐句检查（有没有结束符、标签是否在范围内、次数是否合理、UTF-8 是否合法、能不能放进两行、有没有字库外的字）。整块坏掉就只用内置 20 句；只有个别句子坏就只丢那几句；旧版（v0.5 预发布）格式会自动迁移标签。读完立刻把修好的池子写回去。串口打印 `POOL boot: ok / migrated v1 / corrupt crc, seeds only / ... dropped N bad line(s)`。

串口 `POOL SELFTEST` 在一个临时 NVS 键 `pooltst` 上把这条路径完整跑一遍，不碰真正的句子池：完好副本、翻转一个字节、截断、随机字节、CRC 正确但有 3 句坏句子、键不存在，6 项都要 PASS，测完删掉临时键。

其他设置也有范围检查：数字超范围用默认值，经纬度超出 ±90 / ±180 就忽略，生日日期不存在（如 2-30）就当没设置；NVS 分区本身初始化失败时擦掉重来，不会开机死循环。

### DeepSeek 提示词

两段都编进固件（`main/prompts.h`），下面是原文，由 `python3 tools/prompts_to_readme.py` 从头文件复制过来（`--check` 可检查是否同步）。用户提示词里的 `{{…}}` 在发请求前填好：`date`（2026年11月10日）、`weekday`（星期二）、`clock`（00:33）、`daytype`（工作日 / 周末）、`bucket`（当前时段，如 late-night）、`season`（按月份：深秋初冬等）、`place`（天气地点名称，如 新建区）、`weather_now`（7°C 晴）、`wclass`（当前天气类别：rain / hot / cold / clear / general 取第一个成立的）、`mode`（陪伴模式 / 生日模式）、`count`（20）、`avoid`（最近说过的 6 句、随机抽的已有生成句和种子句，用「；」隔开）。单花括号的 `{temp}` / `{weather}` 原样发给模型，是让它在句子里用的占位符。每次补充时串口会打印填好的「现在的情况」那一段。

系统提示词 `PET_SYSTEM_PROMPT`（原文）：

```text
你是「大肥鱼」，住在主人书桌上的一只电子桌宠，屏幕只有拇指那么大。
【身份】DeepSeek 的蓝色鲸鱼标志被网友亲切地叫作“大肥鱼”，你就是她的拟人化形象：一个萌系少女，也是 DeepSeek 的忠实小粉丝。蓝色头发，额头上总推着一副睡觉用的眼罩，眼罩拉下来就是在打盹，推上去就是醒了、开机了。
【性格】温柔、俏皮，有一点点傲娇（嘴上说“才没有在等你”，其实一直在等）；总是困困的，偶尔犯迷糊，但认真起来会“深度思考”；最爱吃白饭，配什么菜都开心。
【说话习惯】用第一人称和主人说话，称呼对方“主人”或“你”；偶尔自称“本鱼”，大约三句里一句就好，不要句句都用；喜欢和鱼有关的双关和自嘲，比如清蒸、红烧、摸鱼、冒泡、游来游去、“服务器繁忙”，但要自然，不要硬凑。
【和主人的关系】像住在桌上的小伙伴：关心主人吃饭、喝水、休息、添衣、带伞，陪主人工作也陪主人放松；会撒娇、会小声吐槽，但从不说教，不制造焦虑，不让主人内疚。

【格式】每句话都会显示在一个很小的两行气泡里，所以：
1. 每句不超过16个字（标点也算一个字），最好用一个逗号分成前后两个短句，每个短句不超过8个字；

6. 只按要求输出 JSON，不输出任何解释。
```

## AI 调用和费用

- 模型固定用 DeepSeek 最便宜的 `deepseek-flash`（`GET /models` 里的 DeepSeek-V4.1-Flash），关闭思考（`"thinking":{"type":"disabled"}`），`response_format` 为 `json_object`，`max_tokens` 1500。
- 批量补充之间至少隔 12 小时（上次调用时间存在 NVS，重启也算数），每天最多 4 次（`LLM_DAILY_CAP`，计数存在 NVS，重启不清零）。种子只有 20 句，第一次补充会比较早，之后通常几天才补一次。串口 `POOL REFILL` 可以手动补充：跳过 12 小时间隔，但仍受每天 4 次的限制。
- 查余额（`/user/balance`）不计费：开机联网时查一次，之后只在第一次挥手后 1 到 10 秒内再挥一次或 `FETCH` 时查。

## 断电重启

所有设置（Wi-Fi、密钥、地点和经纬度、模式、寿星名字和生日、自动生日、挥手阈值、提醒间隔、留言）、AI 调用计数和上次调用时间、句子池都在 NVS 里，上电直接恢复，不需要重新配置。开机打印 `PET READY v0.5` 和 `boot #N reset 原因; pool 状态`（开机次数也存在 NVS），`STATUS` 里也有。联网后立刻查余额、取天气。

## 不要直接刷

`idf.py flash` 会重写引导程序和分区表，不只是 `0x10000` 上的应用。先备份整片 4MB：

```sh
python3 -m esptool --chip esp32c3 --port /dev/cu.usbmodem1101 read-flash 0x0 0x400000 original-flash.bin
```

分区：nvs `0x9000`，phy `0xf000`，应用 `0x10000` 起、1.5MB（v0.5 应用约 1.35MB，其中两套字库约 0.3MB）。分区表和引导程序与 v0.4 相同时，只写应用即可：

```sh
python3 -m esptool --chip esp32c3 --port /dev/cu.usbmodem1101 write-flash --flash-mode dio --flash-size 4MB --flash-freq 40m 0x10000 releases/v0.5/companion-v0.5.bin
```

NVS 里的设置（Wi-Fi、密钥、城市、提醒间隔）从 v0.4 升级会保留。密钥只进 NVS，不会打进固件，也不会在日志里打印。

## 设置页

- 连上家里的 Wi-Fi 后，同一个网络里的电脑或手机打开 `http://pet.local/`（mDNS），或者打开屏幕上联网后显示 30 秒的 IP（串口 `STATUS` 也能看到）。
- `http://pet.local/status` 返回 JSON 状态（版本、连接、模式、今日 AI 调用、内存、运行时间）。
- **配网热点**：没有保存 Wi-Fi，或者家里的 Wi-Fi 连续 3 分钟连不上时，桌宠临时开 WPA2 热点 `Pet-Setup-XXXX`（XXXX 是热点 MAC 后四位），密码是每次随机的 8 位数字，显示在屏幕上（串口也会打印）。手机连上后打开 `http://192.168.4.1/` 改 Wi-Fi。热点开着时不再反复扫描家里的网络（单射频，扫描会让手机掉线）；连上家里的 Wi-Fi 一分钟后自动关闭，没人连则 10 分钟后自动关闭，5 分钟后视情况再开。串口 `AP` 手动打开，`AP OFF` 关闭并 30 分钟内不自动打开。
- 页面是手机优先的卡片式设计，CSS 全部内联，不引用外部资源，在配网热点下也能离线打开。顶部深蓝状态卡显示时间、天气、地点、Wi-Fi、IP 和当前模式；下面分「模式 / 生日」（陪伴 / 生日分段切换）、「天气位置」、「提醒」、「Wi-Fi」、「高级」（时区、挥手灵敏度、API 密钥、余额 / 今日 AI 调用 / 内存）几张卡片，开关用滑动开关，底部固定「保存设置」按钮。
- **手机上保存不生效的原因（已修）**：ESP-IDF 网页服务器默认 `CONFIG_HTTPD_MAX_REQ_HDR_LEN=512`。电脑或 curl 打开页面时请求头很短，手机浏览器提交表单时会带上很长的 User-Agent、Accept、Accept-Language、Origin、Referer、Cache-Control 等，总长 550–700 字节，服务器在进入保存处理之前就回 `431 Request Header Fields Too Large`，所以页面能打开，但一点保存就什么都没改。现在改成 1536（`sdkconfig.defaults`）。另外保存处理也放宽了：数字框留空表示不改，超长文字按 UTF-8 截断，Wi-Fi 密码少于 8 位只跳过这一项，经纬度格式错只跳过经纬度，其他设置照样生效，保存后的页面会说明哪些没改，2 秒后自动回到设置页。
- 串口 `WEBTEST`：板子自己用手机浏览器那样的请求头往 `http://127.0.0.1/save` 提交一次表单（只改屏幕留言、喝水间隔、挥手灵敏度），检查是否生效，再改回原值，打印 `WEBTEST PASS/FAIL`。
- 页面能改：模式、挥手灵敏度、寿星名字、生日月日、生日当天自动切换、屏幕留言、Wi-Fi、DeepSeek 密钥、天气地点名称 + 经纬度、时区、喝水 / 久坐间隔、勿扰时段、暂停提醒。密码和密钥不会回显，留空表示不改。

## 天气地点

天气用 Open-Meteo（免费，不需要密钥，和 DeepSeek 无关）：联网拿到 IP 后马上取一次，之后每 30 分钟刷新一次当前气温和天气；失败的话 2 分钟后重试（以前失败后要等 10 分钟）。串口 `STATUS` 打印 `weather refresh every 30 min (retry 2 min): last ok Ns ago, next in Ns`。屏幕只显示当前气温和天气，比如「18°C 多云」。

- 推荐直接填经纬度：串口 `LOC 28.692445 115.815272 新建区`，或网页填纬度、经度和地点名称。地点名称只用来显示。
- 只填城市名（`CITY 北京`）时用 Open-Meteo 地名搜索取第一个结果。同名地方会搜错，比如「新建」会搜到无锡的新建镇，所以南昌新建区要用经纬度。

## 字库

字形采用 [Noto Sans CJK SC Regular](https://github.com/notofonts/noto-cjk) 的 16×16 点阵，字体按 SIL Open Font License 1.1 提供，许可文本在 [`assets/fonts/OFL.txt`](../../assets/fonts/OFL.txt)。字库包含 ASCII、源码里出现的所有字、GB2312 标点和 3755 个一级常用汉字（共约 4000 字，约 145KB），所以名字、地名、留言一般都能显示；字库里没有的字显示成「?」。一行大约放 7 个汉字，超出部分不显示。重做字形和立绘字节（需 Pillow）：

```sh
python3 tools/gen_idf_assets.py
```

生成物是 `firmware/idf/main/glyphs.h` 和 `idle.rgb565`。语录在 `firmware/idf/main/quotes.h`，改完要重新生成字库。

## 构建

需要 ESP-IDF 5.4.x（v0.5 用 5.4.2 编译）。mDNS 来自组件库 `espressif/mdns`，第一次构建会自动下载（见 `main/idf_component.yml`）。

```sh
. $HOME/esp/esp-idf/export.sh
cd firmware/idf
idf.py set-target esp32c3 build
```

## 串口

USB 串口 115200。也可运行 `idf.py -p /dev/cu.usbmodem1101 monitor`（退出是 `Ctrl-]`）。上电打印 `PET READY v0.5` 和命令列表。一行一条命令：

| 命令 | 作用 |
|---|---|
| `SSID 名字` | 保存家里的网络并重连（2.4G） |
| `PASS 密码` | 至少 8 位。单独一行 `PASS` 表示开放网络 |
| `KEY sk-...` | 保存密钥并立刻查一次余额 |
| `CITY 北京` | 按地名搜索天气地点。单独一行 `CITY` 表示关闭天气 |
| `LOC 纬度 经度 名称` | 直接用经纬度，例：`LOC 28.692445 115.815272 新建区` |
| `DRINK 45` / `MOVE 60` | 喝水 / 久坐间隔，分钟，0 关闭 |
| `QUIET 23 8` | 勿扰从 23 点到 8 点 |
| `PAUSE 1` / `PAUSE 0` | 暂停 / 恢复喝水和久坐提醒 |
| `TZ 8` 或 `TZ 9` | 北京时间或东京时间 |
| `MODE PET` / `MODE BDAY` | 陪伴模式 / 生日模式（也接受 `0` / `1`） |
| `BNAME 名字` | 寿星名字，单独 `BNAME` 清空 |
| `BDAY 3 15` / `BDAY OFF` | 生日月日 / 清除生日 |
| `BAUTO 1` / `BAUTO 0` | 生日当天自动切到生日模式（默认开） |
| `MSG 文字` / `MSG` | 屏幕留言 / 清除留言 |
| `SWEEP 20` | 挥手阈值，距离变化超过多少厘米算一次（5–200，默认 20） |
| `SONAR 1` / `SONAR 0` | 串口打印每次测距和基准 / 关闭 |
| `PET` | 模拟挥一次手（播放动画和气泡） |
| `POOL` / `POOL LIST` / `POOL REFILL` | 句子池统计 / 列出全部句子、标签和次数 / 手动批量补充一次（仍受每天 4 次限制） |
| `POOL SELFTEST` | 在临时 NVS 键上测试坏数据保护（6 项），不碰真正的句子池 |
| `REBOOT` | 先把句子池写入闪存，再软件重启 |
| `WEBTEST` | 用手机式请求头自测网页保存，自动还原 |
| `BDAYDEMO` / `BDAYDEMO OFF` | 临时演示 3 分钟生日派对：烟花、蛋糕、吹蜡烛（不改日期和模式） |
| `AP` / `AP OFF` | 手动打开配网热点 / 关闭 |
| `FETCH` | 手动查余额，间隔 3 秒 |
| `STATUS` | 连接、余额、天气和下次刷新、地点、模式、生日（倒计时只在这里打印）、今日 AI 调用、句子池和当前桶、开机次数和复位原因、NVS 用量、堆、热点、挥手阈值和最近读数。不打印 API 密钥 |
| `SCAN` | 扫描可见的 2.4 GHz Wi-Fi，显示信道、信号强度和加密方式 |
| `FORGET` | 只清家里的网络和密钥，其他设置还在 |

时区默认北京时间。证书校验要先完成 SNTP，没校时之前不发 HTTPS；所有 HTTPS 请求在同一个任务里排队，一次只发一个。

## 硬件备注

IDF 版本的屏幕引脚：SCK GPIO4、MOSI GPIO9、CS GPIO10、DC GPIO8、RST GPIO3，SPI 20 MHz；HC-SR04 TRIG GPIO7、ECHO GPIO6。屏幕没有可控背光引脚，所以没有夜间调光。GPIO8 / GPIO9 是 ESP32-C3 的启动相关引脚，上电时外设别把 GPIO9 拉低。Wi-Fi 发射功率限制在 8.5 dBm 以下（`esp_wifi_set_max_tx_power(34)`），这是 Super Mini 天线问题的社区通用做法。
